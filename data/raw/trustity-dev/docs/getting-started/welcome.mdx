# Welcome to Trustity Developer Central

**trustity.dev** is Trustity’s developer hub. It is intentionally separate from the customer Cloud Portal (`trustity.io`).

| Surface | Audience | Purpose |
|---------|----------|---------|
| **trustity.io** | Security / IT operators | Deploy agents, set policy, operate vault & audit |
| **trustity.co** | Buyers & prospects | Product marketing |
| **trustity.dev** | Developers & integrators | Technical docs, customer community, changelogs |

## Access model

- Accounts on `trustity.dev` are **independent** of Cloud Portal logins.
- Documentation beyond this public landing requires a Developer Central account.
- Do not reuse Cloud Portal credentials here — create a dedicated account.

## What you will find here

- Platform overview suitable for integrators
- High-level agent ↔ portal integration model
- Authentication concepts for TAO (without exposing exploit-grade internals)
- Changelog for developer-facing notes
- Invite-only **Community** hub (categories, threads, replies, moderation)

Open the Community section after sign-in to ask integration questions and share launch notes with other customers.
