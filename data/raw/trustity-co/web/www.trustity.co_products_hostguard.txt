HostGuard IPS 

Brute-force detection and host firewall blocking - on the endpoint. 

HostGuard watches failed logons, blocks offending IPs with local firewall rules, and reports incidents to the Trustity Cloud Portal - so SecOps can respond before brute-force becomes a breach. 

Request a Demo Request Access Read docs 

Why HostGuard? 

Endpoint enforcement. Blocks at the host firewall - not only a cloud alert. 

Portal visibility. Failed-logon incidents and active blocks surface in the Cloud Portal. 

Part of TAO. Same agent as VisionX, PAM, and GenGuard domain controls. 

HostGuard IPS is the host brute-force module in the TAO agent.
